## Dependencies

- `@supabase/supabase-js` is required for an actual typed browser anon client and typed PostgREST query builder; the platform Fetch primitive cannot supply the generated-schema query typing or browser session behavior.
- `server-only` is required to make the separate service entry fail when imported into browser code; a package export boundary alone does not provide that Next.js enforcement.
- `postgres` is a development-only dependency required to provision and clean integration fixtures through a database-owner test channel without giving `service_role` canonical DML.
- `@types/node` is a development-only dependency for the explicit integration-test environment parsing.
